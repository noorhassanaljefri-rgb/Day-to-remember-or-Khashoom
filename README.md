# A Day to Remember ♡ — دليل التشغيل

موقع دعوة تفاعلي (3 صفحات) + لوحة إدارة خاصة + خادم وقاعدة بيانات.
بدون أي حزم خارجية — يحتاج فقط **Node.js 22.13 أو أحدث**.

## التشغيل للمعاينة (على جهازك)
```
node server.js
```
ثم افتح `http://localhost:3000` (الموقع) و `http://localhost:3000/admin` (الإدارة).
عند أول تشغيل يُنشأ الملف `data/FIRST-RUN-CREDENTIALS.txt` فيه كلمة مرور الإدارة ورموز المحطات المبدئية.
**غيّرها كلها من لوحة الإدارة ثم احذف الملف.**

## النشر (بعد موافقتك النهائية فقط)
أي استضافة تشغّل Node 22+ مع **قرص دائم** لمجلد `data/` (أو استخدم الـ Dockerfile المرفق).
على المنصّات التي تضع الموقع خلف وسيط (Render / Railway / Fly …) اضبط المتغيّر `TRUST_PROXY=1`
حتى تعمل الحماية من تخمين الرموز لكل جهاز على حدة. استخدم HTTPS دائمًا.

متغيرات اختيارية: `PORT` · `DATA_DIR` · `ADMIN_PASSWORD` (قبل أول تشغيل) · `TRUST_PROXY`

## الأمان باختصار
- الرموز السرية تُتحقق على الخادم فقط وتُخزَّن مشفّرة (scrypt)؛ لا تُرسل أي تفاصيل لمحطة مقفلة للمتصفح.
- حماية من التخمين: قفل مؤقت متصاعد لكل جهاز/IP، وقفل لمحاولات دخول الإدارة.
- جلسة الإدارة بكوكي HttpOnly + SameSite=Strict، مع ترويسات CSP وفحص Origin.
- فتح المحطات محفوظ على الخادم مرتبطًا بجهاز الزائر (كوكي)؛ تقدّم القواعد محفوظ على جهازه.
- الصفحة مخفية عن محركات البحث (noindex + robots.txt).
